## 🇧🇷 Sobre mim

Sou dev fullstack e cuido dos sites e sistemas web da Afip, do banco de dados à tela. No dia a dia isso significa:

- 🧱 **APIs e painéis** em Node.js + Express, com telas em EJS
- 🔌 **Integrações** entre sistemas: APIs REST, SQL Server, Google APIs, SharePoint, LDAP, SFTP
- 🤖 **Automação** com RPA (Puppeteer), jobs agendados e tratamento de planilhas
- 🧠 **IA aplicada**: LLMs locais (Ollama) e na nuvem (Gemini) resolvendo problema de verdade
- 🐳 **Docker** em tudo, com segurança levada a sério: JWT, bcrypt, Helmet, rate limit

Fora do trabalho, já fiz termômetro mandar alerta, time de futsal ganhar arte de placar e WhatsApp virar fábrica de figurinha.

## 🇺🇸 About me

I'm a fullstack developer on the Web Systems team at Afip, owning the company's websites and web systems from the database to the UI. Day to day, that means:

- 🧱 **APIs and dashboards** with Node.js + Express and server-rendered EJS views
- 🔌 **Integrations** between systems: REST APIs, SQL Server, Google APIs, SharePoint, LDAP, SFTP
- 🤖 **Automation** with RPA (Puppeteer), scheduled jobs and spreadsheet processing
- 🧠 **Applied AI**: local (Ollama) and cloud (Gemini) LLMs solving real problems
- 🐳 **Docker** everywhere, with security taken seriously: JWT, bcrypt, Helmet, rate limiting

Outside work, I've made thermometers send alerts, given a futsal team automatic scoreboard graphics, and turned WhatsApp into a sticker factory.

### 📂 Things I've built

| | Project | The problem | What I built | Stack |
|---|---|---|---|---|
| 🌡️ | **ThermControl** | IoT thermometers with no history and no alert when readings go off | Dashboard that reads sensors via Home Assistant, stores history and fires alerts | Node · Express · MongoDB · EJS · Docker |
| 🎫 | **AI ticket router** | Service desk tickets triaged by hand | Service that reads each ticket and routes it to the right technician using an LLM | Node · Ollama · Gemini |
| 📄 | **Transparency Portal** | Public documents that must be accessible and protected from abuse | Publishing API and website with rate limiting and hardening | Node · Express · Docker |
| ⚽ | **Match posts** | Match graphics for a futsal team's Instagram made one by one | Generator for match, lineup and scoreboard graphics | Node · Express · MongoDB |
| 💬 | **Sticker bot** | Turning images into stickers was tedious | WhatsApp bot that converts images into stickers instantly | Node · Baileys · Sharp · Docker |

<sub>🔒 Most of these projects are private (work or client code). Happy to talk about the architecture and technical decisions behind any of them.</sub>
